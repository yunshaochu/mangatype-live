# Layout Variant Regression Checklist

## 自动化

- 运行 `npm run test:layout-variants`
- 运行 `npm run build`

## 人工回归

### 1. 翻译成功

- 打开应用并加载一张含对话气泡的图片
- 在设置里把 `Extra Variants` 调到 `1` 或 `2`
- 触发翻译，确认成功生成 bubble，且主文本显示为第 0 组自然译文

### 2. 候选切换

- 选中一个带候选的 bubble
- 在编辑器点击“上一组/下一组候选”，再使用 `Alt+[` / `Alt+]`
- 确认编辑器文本、画布文字和字号同步切换
- 确认没有候选时按钮禁用，快捷键不会报错

### 3. 刷新恢复

- 修改 `Extra Variants` 后刷新页面，确认设置值保留
- 重新打开项目/图片后，确认已有 bubble 不会因为缺少新字段而报错
- 若手动编辑过主文本，确认候选已被清空或失效，不会继续套用旧断点

### 4. 导出一致性

- 在第 0 组与额外候选之间来回切换
- 分别执行画布导出和截图导出（若启用）
- 确认导出结果与当前屏幕上的文本和字号一致

### 5. 历史记录语义

- 生成候选后切换候选，再手动修改主文本
- 执行撤销 / 重做
- 确认主文本、`baseText` 派生结果和候选失效状态随历史一并恢复，不出现错位文本
