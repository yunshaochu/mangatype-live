# BPOOL-080 回归清单（5 条验收）

- 日期：2026-03-06
- 范围：`report.md` 第 7 节 5 条验收标准
- 执行前准备：`npm install && npm run dev`

## 场景 1：任意新建红框可见已有轮廓

1. 导入一张图片并执行本地扫描。
2. 新建一个未参与扫描的新红框，覆盖已有文本区域。
3. 打开轮廓预览开关。

预期：新红框内立即显示橙色轮廓交集。

## 场景 2：同一轮廓被多个红框并行显示

1. 基于场景 1 保持同一轮廓可见。
2. 新建第二个红框与同一轮廓重叠。

预期：两个红框都显示各自交集，互不覆盖或闪烁。

## 场景 3：单框/批量/预擦除仅影响交集区域

1. 对单个红框执行精确填充。
2. 对当前页执行批量填充。
3. 开启预擦除并执行一次去字流程。

预期：交集外像素不被误改；不同红框处理结果互相独立。

## 场景 4：删除初始扫描红框后轮廓仍可访问

1. 删除最初扫描生成的红框。
2. 新建红框覆盖同一区域。

预期：新红框仍可命中并显示/处理对应轮廓。

## 场景 5：DOM/Canvas 导出一致

1. 在同一页面分别切换导出方式为 `canvas` 与 `screenshot`。
2. 各导出一次并对比交集区域结果。

预期：两种导出与编辑器显示一致；无明显所见非所得。
